## Included Apps

### Basic Call Recorder (BCR)
[BCR](https://github.com/chenxiaolong/BCR) v2.8 by [@chenxiaolong](https://github.com/chenxiaolong)
is included as a built-in privileged system app.

BCR is a lightweight call recorder that automatically records incoming and
outgoing calls in the background with no persistent notification.

- **Source:** https://github.com/chenxiaolong/BCR

To exclude BCR from the build, set `WITH_GOKU_BCR := false` in your product
makefile or pass it on the command line.
